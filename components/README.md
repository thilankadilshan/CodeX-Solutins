# Components

This directory contains all reusable UI components for the CodeX Solutions website.

## Planned Structure

```
components/
├── layout/
│   ├── Navbar.tsx          # Sticky navigation with mobile menu
│   ├── Footer.tsx          # Footer with links and social icons
│   └── Section.tsx         # Reusable section wrapper
│
├── ui/
│   ├── Button.tsx          # Primary/secondary/ghost variants
│   ├── Badge.tsx           # Tech tag badges
│   ├── Card.tsx            # Service/portfolio cards
│   ├── AnimatedText.tsx    # Text animation wrapper (GSAP/Framer)
│   ├── GlowOrb.tsx         # Decorative animated glow orbs
│   └── ParticleField.tsx   # Background particle effect
│
└── sections/
    ├── Hero.tsx            # Full-screen hero section
    ├── Services.tsx        # Services grid with animations
    ├── About.tsx           # About us section
    ├── Process.tsx         # Development process timeline
    ├── Portfolio.tsx       # Project showcase
    ├── Technologies.tsx    # Tech stack marquee
    ├── Team.tsx            # Team members
    ├── Testimonials.tsx    # Client testimonials
    ├── Stats.tsx           # Animated counters
    ├── Contact.tsx         # Contact form
    └── CTA.tsx             # Call-to-action section
```
